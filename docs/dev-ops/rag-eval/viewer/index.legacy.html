关于

这是 docs/dev-ops/rag-eval/results/ 下全部评测报告的可视化视图。源文件保持只读， 所有展示数据来自 data/dataset.js，由 build_dataset.py 从 markdown 报告抽取生成。

颜色编码（矩阵 / 单元格）

literal 100% 命中 或 manual_pass=true
literal 部分命中（如 2/3）
literal 全 miss 或 should_answer 但拒答
manual 评分 case（拒答 / 改写 / 概念题），待人评
该 run 没跑这个 case
流程错误（completed=false 或带 error 帧）

视图

  • 矩阵：行=14 个 RAG case，列=过滤后的 run。点单元格弹出该 case 的完整检索 + documents + answer。
  • AB 对比：选 A/B 两个 run，对每个 case 并排列出 literal_hit / retrieved / score_max / top-1 source 等指标的差异。
  • 汇总统计：每个 run 的通过率 / 平均时长 / 字段覆盖度。
